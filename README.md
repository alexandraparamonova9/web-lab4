# Лабораторная №4 — система студентов (Vue)

Vue + Pinia + RxJS, Spring Boot + EclipseLink + PostgreSQL.

## Сделано в части «дизайн и студенты»

- Перенесены исходные стили в `frontend/src/assets/style.css` и котик в `frontend/public/icon.png`. Цвета, таблица, форма, карточка и адаптивная вёрстка сохранены. Новые страницы не используют `static/`; старый фронтенд пока не удалён.
- Добавлены шапка, загрузчик, ошибки, страницы 403/404; список, досье, создание/редактирование и четыре компонента студентов. Изменения доступны ADMIN; удаление требует подтверждения, повторное сохранение блокируется.
- `studentService.js` работает через общий `apiRequest`. Поиск RxJS ждёт 350 мс после ввода; `switchMap` отменяет устаревший запрос через `AbortController`. Подписки освобождаются при уходе со страницы. Уведомления исчезают через 5 секунд.
- Java: фильтры по всем пользовательским полям, включая заметки; ФИО и заметки ищутся по части текста без учёта регистра, остальные поля — по точному значению. Исправлены типы числовых фильтров и PATCH-валидация комнаты. Сортировка разрешена только по известным полям; дополнительный порядок по ID стабилизирует страницы. Размер страницы — 1–100.

## Валидация

Форма проверяет обязательность полей, ФИО без цифр, группу «буква + 4 цифры», целые положительные ИСУ/общежитие/комнату до 2147483647, дату до 31.12.2300 и заметки до 2000 символов. Есть HTML-атрибуты `required`, `min`, `max`, `step`, `maxlength`; при `novalidate` сообщения выводит JS возле полей. ИСУ при редактировании доступен только для чтения. Сервер отдельно проверяет DTO, уникальность и неизменность ИСУ. Ограничение даты до 2300 года сохранено на клиенте из старой формы; сервер требует непустую корректную дату.

Форма готова показывать серверные ошибки из `error.details`. Сейчас общий `api.js` теряет тело ответа — до его доработки показывается общее сообщение по HTTP-коду.

## Что подключить коллеге (её файлы не изменены)

1. В `AppNotifications.vue` исправить импорт `../../composables/useObservable.js`: сейчас реализация лежит в `src/rxjs/useObservable.js`. Либо перенести её в запланированную папку `composables`. Это блокирует общую сборку.
2. В `router/index.js` заменить заглушку `/students` и добавить маршруты:

   | Путь | Компонент из `pages/` | meta |
   | --- | --- | --- |
   | `/students` | `StudentsPage.vue` | `requiresAuth: true` |
   | `/students/new` | `StudentFormPage.vue` | `requiresAuth: true, roles: ['ADMIN']` |
   | `/students/:id` | `StudentDetailsPage.vue` | `requiresAuth: true` |
   | `/students/:id/edit` | `StudentFormPage.vue` | `requiresAuth: true, roles: ['ADMIN']` |

3. В `authStore.js`: после login/register заполнять `user`; `logout()` должен очищать токены и `user` (сейчас обращается к несуществующей `response`). Иначе кнопки ADMIN скрыты и выход не работает. Обработку 401/403 и переходы оставить в общем API/роутере.
4. В `api.js` читать `{ error: { status, message, details } }` и сохранять `status` и `details` в выбрасываемой ошибке. Сохранить передачу `options.signal` для отмены поиска и очередь refresh.
5. В `main.js` подключить `./assets/style.css`, а в `index.html` поставить favicon `/icon.png`. Страницы студентов уже подключают стиль через `AppHeader`; коллега может использовать эту шапку и на своих страницах. В `App.vue` второй раз шапку добавлять не нужно.

## Запуск после подключения каркаса

Скопировать `.env.example` в `.env`, заполнить учётные данные БД и `JWT_SECRET` (Base64-ключ минимум 32 байта: `openssl rand -base64 32`). `.env` не коммитить.

```sh
docker compose up --build
# приложение: http://localhost:5173
# остановка без удаления данных:
docker compose down
```

Для разработки: запустить backend с переменными окружения из `.env`, затем в `frontend` выполнить `npm ci` и `npm run dev`. Vite перенаправляет `/api` на `localhost:8080`. Регистрация создаёт USER; роль ADMIN назначается в БД (`UPDATE users SET role = 'ADMIN' WHERE username = 'имя';`), затем перезапустить backend и войти заново.
